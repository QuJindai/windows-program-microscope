# GUI 原型图提示词（简体中文）

生成方式：built-in image generation tool。
统一约束：1586×992、16:10、深色 Windows 桌面工具；charcoal/slate 面板；琥珀色选中态；青色证据链接；红色故障；灰色不可用；无人物、无水印、无科幻 hologram。七张图必须像同一个“程序显微镜”工作台的不同镜片。

界面可见文案统一使用简体中文。`REAL`、`DERIVED`、`UNAVAILABLE`、`DEBUG_ONLY`、`ETW`、`MTP`、`CRC`、`WSAETIMEDOUT`、进程名和路径等属于技术标识，可保留英文，避免和真实日志字段脱节。

## 00 — 开始采集

Use case：ui-mockup
主要求：独立 Windows 程序显微镜的采集设置页。
必须显示：`开始采集会话`、`选择目标进程`、`观察（推荐）`、`深度追踪`、`时间旅行`、持续时间、PID 范围、敏感数据处理、预计存储、带 `真实/派生/不可用/仅调试` 的能力清单，以及“没有提供程序上报就不声明数据”。
人的问题：开始采集前，我会看到什么，代价是多少？

## 01 — 总览

Use case：ui-mockup
主要求：显示“程序正在等待设备响应”的程序体检报告。
必须显示：CPU、内存、线程、模块、文件、网络、异常；最近的重要事件；可能原因；选中的超时事件和证据检查器；始终存在的执行时间线。
人的问题：程序现在在做什么？

## 02 — 时间线

Use case：ui-mockup
主要求：展示“点击打开 → 网络请求 → 等待 → 超时”的执行时间线。
必须显示：线程、CPU、内存、磁盘、文件、注册表、网络、锁与等待、异常、DLL 加载、用户操作；时间游标位于 8.372 秒；事件检查器；底部导航时间线。
人的问题：什么时候发生了什么？

## 03 — 流程

Use case：ui-mockup
主要求：高亮真实执行节点，淡化未执行分支。
必须显示节点：启动、打开项目、加载设置、读取文件、解析 JSON、连接设备、读取设备、校验 CRC、重试、回退、超时；选中的“校验 CRC”检查器；路径图例和永久时间线。
人的问题：这次程序实际走了哪条路线？

## 04 — 状态

Use case：ui-mockup
主要求：暂停在 8.372 秒，展示线程、调用栈、参数、局部变量、内存摘要和值来源。
必须显示：`result=false`、`校验 CRC`、`actualCrc`、`读取设备`、网络响应；真实/派生/不可用标签；源代码片段；“追踪这个值”操作。
人的问题：当时内部是什么状态，这个值从哪里来？

## 05 — 输入/输出

Use case：ui-mockup
主要求：展示点击打开后的 Windows 影响。
必须显示标签：文件、注册表、网络、模块、子进程、句柄；摘要“打开 12 个文件，联系 2 个端点，加载 3 个模块”；选中的网络请求；源线程；证据真假标记。
人的问题：程序对 Windows 世界改变或访问了什么？

## 06 — 对比

Use case：ui-mockup
主要求：并排展示“运行 A · 正常”和“运行 B · 失败”，并对齐执行阶段。
必须显示：首次分叉“读取设备 → 校验 CRC”、时间/持续时间/结果、正常 CRC 与 `0x9C4D`、重试 ×3、超时、分叉检查器、同步双时间线。
人的问题：为什么这次运行不同？
