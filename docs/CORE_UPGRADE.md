## Windows 数据能回答什么

本版可以核验某个进程何时创建线程、加载模块、请求文件读写、访问哪些注册表键和值，以及发起哪些 TCP 操作。CPU、内存曲线来自真实采样。事件中的请求字节数与实际完成字节数分别理解，不把未记录的操作耗时补成零。

“为什么产生某个变量值”需要显式数据来源边或额外插桩。ETW 只提供系统事件时，流程图的灰色顺序关系仅表示时间先后；琥珀色来源图只使用记录中的显式关系。任意原生局部变量、完整内存及指令级时间旅行仍不可用。
