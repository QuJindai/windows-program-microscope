# Windows 程序显微镜 V0.2 实施规格

目标：将 GUI 从示例查看器升级为本地运行证据工具。公开独立仓库，简体中文，以既有七张原型为视觉基准。用户已授权开发、测试和提交仓库；无需重新确认设计。

## 接口冻结
桌面 `window.__TAURI__.core.invoke` 调用：
- `runtime_status` -> {platform, collector_available, reason, capabilities:[]}。
- `list_processes` -> [{pid,name,path,arch}]，失败必须报错。
- `start_capture` 参数 {pid, durationSeconds} -> {id,status}，只允许一个活动会话。
- `capture_status` 参数 {id} -> {id,status,trace?,error?}，status: running/completed/failed/cancelled。
- `stop_capture` 参数 {id} -> 会话状态。通过采集器控制输入 stop 正常结束并保留结果。
- `list_traces` -> run 数组；`load_trace` 参数 {id} -> MTP。
- `save_trace` 参数 {trace} -> run（严格检验，原子持久化；无任意路径参数）。
- `inspect_pe` 参数 {path} -> 真实 PE 元数据（如果实现不了明确不可用）。

Collector CLI: --list-processes 返回 JSON 数组；--capabilities 返回 JSON；--pid N --duration N --out FILE 真实采集，stdout 仅诊断，stdin 的 stop 控制停止。使用 TraceEvent 3.2.6。保留 schema_version 0.1 兼容，增加 counters/capabilities/resources/diagnostics。所有 collection 始终数组。没有证据不得补零或把示例当运行。单次事件限额 100000，时长 1..3600 秒。

分析 JS CommonJS + browser UMD 模块 `app/trace-core.js`，全局 `TraceCore`：validateTrace(trace)->string[]；summarize(trace)->object；firstDivergence(a,b)->object|null；provenance(trace,id)->array；buildGraph(trace)->{nodes,edges}；reachable(graph,id,direction)->{nodes,edges}；shortestPath(graph,from,to)->{nodes,edges}；toPerfetto(trace)->object。并维护 Python engine 同等核心语义。比较不依赖跨线程插入噪声事件的绝对序号；证据追溯支持分叉。时间邻近仅序列关系，不自动升级为因果。

GUI 全局 210px 侧栏、固定底部时间轴、可滚动内面板。总览/时间线/流程/状态/I-O/对比/采集七页，1440×900 及 1600×1000 无主体溢出。选择事件跨镜片联动；导入文件校验失败保留当前有效 trace；导出 MTP/Perfetto。示例必须用户主动打开并持续标记“示例数据”，不能启动自动 fallback。真实采集完成通过 bridge 获取保存结果。不得展示虚构 CPU 曲线、局部变量、内存、调用栈或网络连接数。未采集项显示“未采集/不可用”。

Windows 验证使用 GitHub Windows Runner 执行真实文件/注册表/本机 TCP/线程探针；编译和 ETW 运行分别报告。完整指令级 Time Travel 与任意原生局部变量不由 ETW 自动提供，在 GUI 中禁用并说明。
